## Pricing Assumptions

- Provider pricing source and access date: Google Gemini Developer API pricing, <https://ai.google.dev/gemini-api/docs/pricing>, accessed 2026-10-02 (Standard tier, paid).
- `gemini-3.1-flash-lite` input price: USD 0.25 per 1M tokens (text).
- `gemini-3.1-flash-lite` output price: USD 1.50 per 1M tokens, including thinking tokens.
- Cached-input price: N/A. Provider context caching is not used; the application's own response cache serves repeat prompts locally, so a cache hit makes no provider call and costs USD 0.
- Calculation formula and rounding rule: `cost = input_tokens / 1,000,000 x input_price + (output_tokens + thinking_tokens) / 1,000,000 x output_price`, rounded to 6 decimal places per call. Totals are sums of the rounded per-call values.
- Token source: `usage_metadata` returned by the Gemini API (`prompt_token_count`, `candidates_token_count`, `thoughts_token_count`). Mock rows (if any) use a chars/4 estimate and are costed at USD 0.
- Retries: tokens are summed across attempts that returned a response. An attempt that timed out returns no usage data, so it is counted in `Retries` and `Latency` but contributes 0 tokens here; the provider may still bill it. Latency is wall-clock time for the whole logical call, including failed attempts and backoff.
- Providers in this log: gemini, mock.

## What Triggers an LLM Call

Only the SOP-03 diagnosis-consistency step calls the LLM, at most once per review. It is skipped deterministically when the claim diagnosis is blank (already a SOP-01 finding) or when the claim and discharge diagnoses match exactly with no uncertainty wording. In the supplied data that means CASE-001, CASE-003, CASE-007 and CASE-008 make no LLM call, and the other six cases make one call each.

## Unit Economics

- One full pass over the 10 supplied cases (`canonical-live`): 6 LLM calls, USD 0.002774, i.e. about USD 0.000277 per case.
- Projected at 10,000 cases/month with the same mix: about USD 2.77/month in LLM spend (before cache hits).
- The main cost driver is the fixed system prompt (SOP-03 and SOP-06 text plus instructions, about 700 tokens). Provider-side context caching or batch pricing would cut it further.
